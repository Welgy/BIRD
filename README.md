# Bird Game (C++)

A simple console arcade game about a bird, written in C++.

## Controls

- Space — jump

## Features

- Bird movement and jump mechanics
- Gravity (the bird falls down)
- Obstacles with gaps
- Collision detection
- Rendering in the console

## Getting Started

Requires a `g++` compiler (C++11 or newer).

```bash
g++ main.cpp -o bird
./bird
```
